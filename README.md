# FacturasSAT-distribucion

Distribucion automatica y actualizaciones de Facturas SAT.

La persona usuaria final solo debe abrir `FacturasSAT_Lanzador.exe`. El lanzador instala la aplicacion en `%LOCALAPPDATA%\FacturasSAT`, busca actualizaciones al iniciar, verifica SHA-256 y abre la aplicacion aunque el servidor no este disponible.

Los ejecutables grandes se publican en GitHub Releases junto con `version.json`. No se deben compartir contrasenas, XML, PDF ni registros fiscales reales.
